# Install the Omarchy plugin

The Omarchy plugin route remains available separately from native installation. Add the plugin, then explicitly enable it in the host.

```sh
omarchy plugin add /path/to/fileblade --yes
omarchy plugin enable data-goblin.fileblade
```

Demonstration: The local plugin candidate is added to the disposable host profile.

The clip stops at installation and explicitly reports that enabling is still required. It does not prove plugin runtime loading.
