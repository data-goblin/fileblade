# Open an extension bar popout

An extension bar button can open a FileBlade popout using the host component. The extension owns the content while FileBlade provides the popout surface.

Demonstration: The real Goblins bar widget opens its gallery popout.

This is component qualification through FileBlade's explicit harness. It does not establish ordinary native bar integration as release-ready.
