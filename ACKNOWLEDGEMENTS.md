# Acknowledgements

This file was written by an agent.

FileBlade is shaped by the people who send code, ideas and bug reports. Each
entry names what they gave and where; a feature built from someone's idea or
pull request credits them even when the code that shipped was rewritten.

## Code

- Font size setting that scales blade text from 75% to 200%: [@YuriRCosta](https://github.com/YuriRCosta) ([#2](https://github.com/data-goblin/fileblade/pull/2))
- Copying paths and files keeps the clipboard filled after FileBlade's helper exits: [@YuriRCosta](https://github.com/YuriRCosta) ([#5](https://github.com/data-goblin/fileblade/pull/5))

## Ideas

- Blades on one monitor only, which became the Monitors setting: [@chrispository](https://github.com/chrispository) ([#1](https://github.com/data-goblin/fileblade/issues/1))
- Dragging files out of a blade into other applications: [@YuriRCosta](https://github.com/YuriRCosta) ([#4](https://github.com/data-goblin/fileblade/pull/4), [#13](https://github.com/data-goblin/fileblade/pull/13))
- Back and forward mouse buttons that walk the blade history: [@YuriRCosta](https://github.com/YuriRCosta) ([#6](https://github.com/data-goblin/fileblade/pull/6), [#14](https://github.com/data-goblin/fileblade/pull/14))
- A settings scrollbar that stays out of the rows: [@vdvoorder](https://github.com/vdvoorder) ([#9](https://github.com/data-goblin/fileblade/pull/9))
- Mount, unmount and eject results that report success to the Drives pane: [@vdvoorder](https://github.com/vdvoorder) ([#10](https://github.com/data-goblin/fileblade/pull/10))
- Focusing a module keeps the tab that already shows it: [@vdvoorder](https://github.com/vdvoorder) ([#11](https://github.com/data-goblin/fileblade/pull/11))
- Page Up and Page Down page a hovered preview: [@vdvoorder](https://github.com/vdvoorder) ([#12](https://github.com/data-goblin/fileblade/pull/12))
- An overlay setting so blades stop reserving screen space: [@rabfulton](https://github.com/rabfulton) ([#36](https://github.com/data-goblin/fileblade/issues/36))

- Companion extensions could not find FileBlade after Omarchy restricted plugin registry access: [@wundrellama](https://github.com/wundrellama), [@PeterHennesey](https://github.com/PeterHennesey) ([#3](https://github.com/data-goblin/fileblade/issues/3))
- The bundled backend was x86-64 only, so FileBlade did not start on aarch64: [@Skeptomenos](https://github.com/Skeptomenos) ([#7](https://github.com/data-goblin/fileblade/issues/7))
- Removing FileBlade left its companion extensions installed and waiting for it: [@Linar46](https://github.com/Linar46) ([#8](https://github.com/data-goblin/fileblade/issues/8))
- Copy path and Copy never reached the system clipboard: [@manualecarvajal-collab](https://github.com/manualecarvajal-collab) ([#15](https://github.com/data-goblin/fileblade/issues/15))
- File preview showed a raw ELOOP error for symbolic link cycles: [@RajdeepVerma](https://github.com/RajdeepVerma) ([#18](https://github.com/data-goblin/fileblade/issues/18))
- The 0.2.0 migration refused to run once the legacy plugin was fully removed: [@RajdeepVerma](https://github.com/RajdeepVerma) ([#22](https://github.com/data-goblin/fileblade/issues/22))
- Notes were read-only after login because the launcher accepted an empty plugin list: [@RajdeepVerma](https://github.com/RajdeepVerma) ([#23](https://github.com/data-goblin/fileblade/issues/23))
- The right-click menu closed before an item could be picked: [@rabfulton](https://github.com/rabfulton) ([#35](https://github.com/data-goblin/fileblade/issues/35))
